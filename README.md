# Group five, TW4Tech Solutions

This repository contains technical documentation deliverables by Group 5, produced for the TW4Tech Solutions technical writing training program.

## About

As part of the program, we were assigned Hackmamba, a technical content company that publishes open-source projects on GitHub. This made the project well suited to the capstone, as both the project and our documentation are publicly accessible.

For the capstone, we created a complete documentation set covering a README audit, user and installation guide, developer guide, API documentation, and technical blog post.

## Deliverables

| Deliverable | Description | Location | Status |
| --- | --- | --- | --- |
| README Audit | A concise critique identifying gaps in the project's README | [Hackmamba README Audit](./Hackmamba-Docs-README-Audit.md) | Published |
| User and Installation Guide | Instructions for users to install and use the product | Coming soon | In progress |
| Developer Guide | Documentation for developers working with or contributing to the project | Coming soon | In progress |
| API Documentation | Reference documentation for the project's API | Coming soon | In progress |
| Technical Blog Post | A technical article explaining an aspect of the project | Coming soon | In progress |
